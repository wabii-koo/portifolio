# Welebe Kebede – Personal Portfolio

A modern, responsive developer portfolio built with **Next.js 16**, **React 19**, **TypeScript**, and **Tailwind CSS v4**. It showcases my projects, technical skills, experience, and provides a contact form powered by Resend.

## ✨ Features

- Modern and responsive UI
- Project showcase with live demos
- Skills and experience sections
- Downloadable CV
- Contact form with Resend integration
- SEO optimized
- Smooth animations and dark theme

## 🛠️ Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4
- Resend API
- Vercel

## 🚀 Getting Started

```bash
git clone https://github.com/wabii-koo/portifolio.git
cd portifolio
npm install
npm run dev
```

Open `http://localhost:3000`.

## 🔐 Environment Variables

Create a `.env.local` file:

```env
RESEND_API_KEY=your_resend_api_key
CONTACT_EMAIL=your_email@example.com
```

## 📦 Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```
